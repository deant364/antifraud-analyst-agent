Профессиональный антифрод-разбор сайта

Агент помогает быстро и понятно оценить: какие данные сайт может узнать о пользователе, насколько это рискованно, есть ли признаки автоматизации, почему выставлен такой балл и что аналитику проверить дальше.

Поле используется как название проверки. Если проект развернут на Vercel, кнопка «Анализ URL» попробует запросить серверный API и проверить HTML сайта. Если API недоступен, сайт требует авторизации или скрыт личным кабинетом, агент покажет понятное сообщение. Для анализа такой страницы вставьте сохранённый HTML/JS в раздел «Анализ кода».
