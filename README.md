# Антифрод-Аналитик

Профессиональный инструмент для антифрод-анализа веб-ресурсов и клиентского кода.

## Основные возможности

- Анализ веб-ресурсов по URL
- Анализ HTML и JavaScript
- Выявление систем аналитики и трекеров
- Поиск признаков fingerprinting
- Выявление сбора пользовательских данных
- Анализ потенциально рискованных сценариев
- Формирование итогового отчёта
- Экспорт результатов в JSON

## Для кого предназначен

- Антифрод-аналитики
- Специалисты по информационной безопасности
- Риск-аналитики
- Compliance-команды
- Исследователи веб-ресурсов

## Технологический стек

- HTML
- CSS
- JavaScript
- Node.js

## Назначение

Инструмент помогает быстро провести первичный анализ веб-ресурса и обнаружить признаки отслеживания пользователей, профилирования устройств, использования аналитических систем и других потенциально значимых механизмов сбора данных.
